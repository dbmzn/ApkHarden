# 通用开发工具

[返回 README](../README.md) · [常见问题](FAQ.md)

侧栏「通用工具」提供 JSON、文本对比、编码解码、时间工具。按 **⌘K / Ctrl+K** 可以从主窗口打开工具搜索，输入名称或关键字后选择工具。

这些工具无需连接设备，在本机处理数据。各工具的输入和结果在本次应用会话中保留，切换标签或暂时离开通用工具页不会清空；关闭应用后清除。不会自动读取剪贴板或保存输入历史。

## JSON

- **格式化 / 压缩**：调整布局，不将数字先转成浮点数，保留大整数和高精度小数。
- **校验**：展示解析错误及可获取的行列位置；拒绝重复字段，避免格式化后覆盖同名字段。
- **树形查看**：展开 / 收起对象与数组，搜索字段、路径或值，点击「路径」复制该节点的 JSONPath。
- **JSONPath**：支持字段、数组索引、通配符、递归查找与条件比较。查询结果显示在输出区，不覆盖输入。
- **作为右侧对比**：把当前输出送入对比工具的右侧，并启用 JSON 字段比较。

以内置示例为例：

```text
$.items[*].name
$.items[0].price
$.items[?(@.price < 10)].name
$..name
```

暂不支持 JSONPath 正则过滤。直接字段查询保留大整数与小数；聚合函数的具体数值行为由 JsonPath 库决定。

## 文本与 JSON 对比

普通模式逐行对比，新增、删除和替换在左右列高亮。可忽略空白、交换左右内容、只显示变化及复制差异摘要。

JSON 模式按字段路径比较：

- 对象字段顺序不影响结果。
- 数组顺序有意义；数组元素按索引比较。
- 字符串内的空白有意义，不使用普通文本的“忽略空白”规则。
- 缺失字段和 `null` 不相同。
- 数值 `1` 与 `1.0` 按相同数值处理。

界面中长值预览最多显示前 800 字符；「复制差异」保留完整值。导出的摘要用于阅读，不是可直接执行的 Git patch。

## 编码解码

| 格式 | 行为 |
| --- | --- |
| URL 组件 | 编码单个路径或参数值；空格为 `%20`，解码时保留 `+` |
| 表单 URL | `application/x-www-form-urlencoded` 规则；空格与 `+` 互转 |
| Base64 | UTF-8 文本与标准 Base64；解码允许输入含空白或换行 |
| Base64 URL | URL 安全字母表，编码不带末尾填充等号 |
| Unicode | 非 ASCII 字符和反斜杠编码为 `\uXXXX`，支持 Emoji 代理对；拒绝不完整转义或孤立代理项 |
| HTML 实体 | 编码 `& < > " '`；解码常用命名实体及十进制 / 十六进制数字实体，未知命名实体原样保留 |
| JSON 字符串 | 编码生成带外层引号的 JSON 字符串；解码必须提供完整字符串字面量 |
| JWT | 解析三段式 JWT 的 Header / Payload，显示 exp 的 UTC 时间与过期状态；不验证签名 |

URL 和 Base64 的文本解码使用严格 UTF-8；二进制内容或损坏的字节不会用乱码悄悄替代。非 JWT 格式可将结果作为输入并反转处理方向，方便往返检查。

HTML 常用命名实体包括 `amp`、`lt`、`gt`、`quot`、`apos`、`nbsp`、`copy`、`reg`、`trade`、`hellip`、`mdash`、`ndash`。

## 时间与 Cron

### 时间戳与日期

- 可明确选择秒或毫秒；自动模式识别 10 位秒、13 位毫秒，其他长度需手动选单位。
- 本地日期支持 `yyyy-MM-dd HH:mm:ss` 及可选小数秒；也支持带 `Z` 或偏移的 ISO 8601 日期。
- 未写偏移的日期按选定 IANA 时区解析，例如 `Asia/Shanghai`；带偏移的日期按其明确的时间点解析，再转换为选定时区显示。
- 结果同时展示当地时间、UTC、秒与毫秒时间戳。
- 夏令时跳跃区间的不存在时间会报错；回拨时的重复时间需要显式填写偏移，例如 `-04:00`。

### 时间差

计算“结束 − 开始”，显示天 / 时 / 分 / 秒、总秒数和总毫秒数，并列出两个 UTC 时间点。支持负差值及小数秒。

### Cron 预览

| 语法 | 字段 | 示例 |
| --- | --- | --- |
| Unix 5 位 | 分 时 日 月 周 | `*/5 * * * *` |
| Spring 6 位 | 秒 分 时 日 月 周 | `0 */5 * * * *` |

选择时区并填写基准日期，留空则使用点击时的当前时间。显示严格晚于基准的未来 5 次执行时刻，附带时区偏移。此功能只做计算，不会创建或运行任务。

## 输入与显示限制

- 每侧文本输入最多 500,000 个字符；打开的 UTF-8 文件最多 2 MB，并仍受字符数量限制。
- JSON 嵌套最多 128 层，格式化或编码后的输出最多 2,000,000 字符。
- 树形查看最多显示 3,000 项，超出后提示缩小搜索范围。
- 普通文本对比每侧最多 5,000 行；JSON 对比最多 3,000 处差异。
- JSONPath 最长 1,000 字符；Cron 表达式最长 300 字符。

这些限制用于保持桌面交互流畅，达到限制时会明确提示。

## 开发与验证

核心逻辑位于 `src/main/kotlin/com/apkharden/packager/core/developer/`，界面和会话状态位于 `src/main/kotlin/com/apkharden/packager/ui/developer/`。

```sh
./gradlew test --tests 'com.apkharden.packager.core.developer.*'
```

测试覆盖精度、错误位置、重复字段、JSONPath、树形展开、差异对齐、编码往返、非法 UTF-8、时区 / 夏令时和 Cron 边界。

依赖：[JsonPath](https://github.com/json-path/JsonPath)、[cron-utils](https://github.com/jmrozanec/cron-utils)、[java-diff-utils](https://github.com/java-diff-utils/java-diff-utils)。具体版本见 [build.gradle.kts](../build.gradle.kts)。
